Projects:

Yellow-Forge AI 

YellowForge AI is an intelligent Streamlit app generator that transforms plain ideas or PDF requirements into complete, production ready Streamlit applications in seconds. Powered by Groq’s Llama 3.1 model, it generates clean Python code, modern UI designs, and a full project package including app code, dependencies, and documentation. With customizable themes, responsive layouts, and instant downloads, YellowForge AI streamlines app creation and helps developers move from concept to working prototype with speed and confidence.

Link: https://github.com/AlyaanKhan/Streamlt_app_generator

KnowledgeAi:

KnowledgeAI is an AI powered YouTube knowledge extraction platform that converts videos into structured learning materials such as summaries, chapter breakdowns, flashcards, quizzes, and key definitions. Using FastAPI on the backend, a modern React frontend, and Groq powered LLaMA and Whisper models, it delivers fast transcription, deep semantic analysis, and real time feedback through a polished light and dark themed interface. The platform is designed to help learners quickly understand, revise, and retain knowledge from long form video content with clarity and speed.

Link: https://github.com/AlyaanKhan/Youtube_Knowledge

QueryGenius:

QueryGenius is an AI powered data query platform that lets users explore datasets using natural language with no SQL required. Users can upload CSV or Excel files, ask complex questions in plain English, and instantly get results, generated SQL, and interactive visualizations. Built with a React frontend and FastAPI backend using LangChain and Groq’s LLaMA 3.1 model, QueryGenius combines smart data analysis, query management, and modern dashboards to make data exploration fast, intuitive, and powerful.

Link: https://github.com/AlyaanKhan/Query_generator
